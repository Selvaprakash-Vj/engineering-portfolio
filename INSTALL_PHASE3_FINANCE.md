# Install Phase 3.3

1. Stop Vite with `Ctrl + C`.
2. Extract this update directly into `D:\Engineering_Portfolio`.
3. Allow Windows to replace `src\App.tsx`, `src\site.ts`, and `src\styles.css`.
4. Restart with:

```powershell
cd D:\Engineering_Portfolio
npm run dev
```

No new npm dependency is required.

Direct case-study URL:

`http://localhost:5173/?project=finance-tracker`
