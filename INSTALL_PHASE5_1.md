# Phase 5.1 — Mobile Experience Refinement

This update changes only the mobile composition at widths of 680 px and below.

## Changes

- Removes the decorative rotor from the mobile hero.
- Preserves the complete desktop hero unchanged.
- Removes the duplicate mobile career-route block.
- Converts the real experience tabs into a compact horizontal swipe/tap navigator.
- Keeps the selected job description directly below the navigator.
- Preserves the desktop Career Log unchanged.

## Install

Copy the update files into `D:\Engineering_Portfolio`, replace existing files, then run:

```powershell
npm run build
npm run dev
```
