# Selva Engineering Portfolio — Sections 02 & 03 Update

This upgrade is designed for the existing project at:

`D:\Engineering_Portfolio`

## Install

1. Stop the Vite server with `Ctrl + C`.
2. Extract this ZIP directly into `D:\Engineering_Portfolio`.
3. Allow Windows to replace the three files inside `src`.
4. Restart:

```powershell
cd D:\Engineering_Portfolio
npm run dev
```

No new npm packages are required.
