# Phase 6.1 — Bilingual Core

This release adds a complete German homepage and German digital-resume route while preserving the existing English portfolio and project case studies.

## Routes

- English portfolio: `/`
- German portfolio: `/de/`
- English digital resume: `/resume`
- German digital resume: `/de/lebenslauf`

## Included

- EN / DE switch in the main navigation and resume top bar
- German translations based on the current German CV and master CV
- German career, expertise, education, certification and contact content
- German downloadable CV document
- Language-specific metadata, canonical URLs and hreflang links
- German sitemap entries and GitHub Pages route shells

MachineGuard AI and Finance Tracker remain English in this phase and will be translated in the next bilingual project phase.
