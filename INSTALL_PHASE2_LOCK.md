# Install the Phase 2 Lock Update

1. Stop Vite with `Ctrl + C`.
2. Extract this ZIP directly into:

```text
D:\Engineering_Portfolio
```

3. Allow Windows to replace:

```text
src\App.tsx
src\styles.css
```

4. Restart:

```powershell
cd D:\Engineering_Portfolio
npm run dev
```

No `npm install` is required.
