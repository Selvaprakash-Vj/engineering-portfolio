# Install Phase 4.5

1. Stop the local Vite server with `Ctrl + C`.
2. Back up `D:\Engineering_Portfolio` if desired.
3. Extract the Phase 4.5 update ZIP directly into `D:\Engineering_Portfolio`.
4. Allow Windows to replace the included files.
5. Your existing résumé PDF in `public` is not replaced by the update.
6. Run:

```powershell
cd D:\Engineering_Portfolio
npm run build
npm run preview
```

For development:

```powershell
npm run dev
```
