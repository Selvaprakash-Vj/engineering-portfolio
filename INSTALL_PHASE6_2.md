# Install Phase 6.2

1. Stop Vite with `Ctrl + C`.
2. Extract the update ZIP directly into `D:\Engineering_Portfolio`.
3. Allow Windows to replace the included files.
4. Run:

```powershell
cd D:\Engineering_Portfolio
npm run build
npm run dev
```

Test:

- `http://localhost:5173/projects/machineguard-ai`
- `http://localhost:5173/de/projekte/machineguard-ai`
- `http://localhost:5173/projects/finance-tracker`
- `http://localhost:5173/de/projekte/finance-tracker`

The language switch should preserve the active project page.
