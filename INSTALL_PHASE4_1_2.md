# Install Phase 4.1 + 4.2

1. Stop Vite with `Ctrl + C`.
2. Extract this ZIP directly into `D:\Engineering_Portfolio`.
3. Allow Windows to replace the included files.
4. Your existing `public\Selvaprakash_Vijayaraman_Resume.pdf` is not replaced or deleted.
5. Restart:

```powershell
cd D:\Engineering_Portfolio
npm run dev
```

Test:

```text
http://localhost:5173/
http://localhost:5173/projects/machineguard-ai
http://localhost:5173/projects/finance-tracker
http://localhost:5173/resume
```
